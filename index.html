MOSAIC Storage

Working and tested. Follow these steps to browse and play videos stored on your MOSAIC PowerStick using VLC for iPad 3.7.4.

  1. Connect to MOSAIC Wi-Fi.On your iPad, open Settings → Wi-Fi and join the wireless network from your PowerStick. Stay connected to it.
  2. Open VLC and add a server.In VLC, go to Network and choose Add Server / Connect to Server.
  3. Enter the server details.Choose SMB if asked. For the server address, enter 192.168.10.1.
  4. Sign in.Username: admin. Password: enter the admin password for your PowerStick. If it has never been changed, the default may be admin.
  5. Open the storage folders.After connecting, open Public, then SDA1.
  6. Choose a video and play.Tap a video in VLC to play it directly from the PowerStick.

Tested successfully on VLC for iPad 3.7.4. Keep file access read-only: do not delete, rename, move, overwrite, or upload files.

Storage information ＋

Storage access is working. On iPad, VLC 3.7.4 connects to the PowerStick over SMB, opens Public → SDA1, and plays videos directly from the device.

The storage itself is fully usable through the tested VLC workflow. A separate future enhancement would be letting this website browse or stream files directly; ordinary GitHub Pages cannot directly open SMB connections.
