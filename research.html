06 · Connect to MOSAIC storage with VLC

A real-device test confirmed that VLC for iPad (version 3.7.4) can connect to the PSTR2 over its local Wi-Fi network, browse the storage folders, and play a video directly from the PowerStick.

TESTED WORKFLOW · VLC FOR IPAD 3.7.4

Step-by-step connection instructions

  1. Join the MOSAIC Wi-Fi network.
    On your iPad, open Settings → Wi-Fi and connect to the wireless network broadcast by your MOSAIC PowerStick. Stay connected to that network while using VLC.
  2. Open VLC.
    Launch VLC for iPad. This test was completed with version 3.7.4.
  3. Add a network server.
    In VLC, open the Network area and choose the option to add or connect to a server (the exact label can vary by VLC version).
  4. Enter the MOSAIC server address.
    Use 192.168.10.1 as the server IP address and select SMB if VLC asks for the network protocol.
  5. Enter the sign-in details.
    Use admin as the username for the tested setup, then enter the password configured on your own PowerStick. The default used during the owner's test is intentionally not reproduced in this public guide.
  6. Connect and open the folders.
    After the SMB connection succeeds, open Public, then SDA1. This takes you into the MOSAIC storage volume.
  7. Browse and play media.
    Choose a media file in VLC. The owner successfully played a video directly from the PowerStick during testing.
Verified result: VLC 3.7.4 on iPad connected to 192.168.10.1 over SMB, navigated through Public → SDA1, and played a video from the device. This confirms practical media access through VLC; it does not yet prove that Safari or a GitHub Pages website can connect to SMB.
KNOWN NETWORK DETAILS

What the test used

  • Client: VLC for iPad, version 3.7.4
  • Server IP: 192.168.10.1
  • Protocol: SMB
  • Username: admin
  • Folder path after connecting: Public → SDA1
  • Observed outcome: browsed files and played a video
SAFETY & LIMITATIONS

Read-only research only

Do not delete, rename, move, overwrite, upload, or edit files on the PowerStick. Do not publish device passwords or expose its local administration services to the public internet.

Apple Files did not connect successfully in the owner's test, but the exact error and negotiated SMB dialect have not been recorded. SMB1 remains an unverified hypothesis.

A static browser site on GitHub Pages cannot directly open SMB connections or raw TCP sockets. Browser-based storage access still needs a compatible HTTP interface or a separate local bridge.

08 · Hardware identification: processor and battery

The owner's board photographs appear to show a Ralink RT5350F system-on-chip. The battery label identifies a 4,500 mAh pack. This section separates visible markings and datasheet specifications from details that still need a clearer photograph or technician inspection.

OWNER-REPORTED BOARD LAYOUT

Two stacked circuit boards

  • Upper board: The owner reports that the Ralink RT5350F chip is on this board.
  • Lower board: The owner suspects this board contains the USB hardware; this is not yet verified.
  • Battery: The owner reports that the lithium battery is soldered into the board assembly.

The exact purpose of the lower board, board-to-board connection, battery solder points and component locations remain unknown. We are not assigning functions based on appearance alone.

CHIP IDENTIFIED FROM OWNER PHOTO

Ralink RT5350F networking SoC

Marking: RT5350F · Manufacturer: Ralink Technology (later part of MediaTek).

  • 360 MHz MIPS 24KEc processor core
  • Integrated 2.4 GHz 802.11b/g/n 1T1R wireless networking
  • Integrated five-port 10/100 Ethernet switch/PHY
  • USB 2.0 host/device interface
  • 16-bit SDR SDRAM interface, supporting up to 64 MB
  • Peripheral interfaces include SPI, I²C, UART, I²S, PCM and GPIO

These are capabilities of the chip itself. They do not prove which interfaces MOSAIC actually wires up, its RAM or flash capacity, or which firmware it runs.

BATTERY · PACK DETAILS NOT YET VERIFIED

4,500 mAh lithium battery

The external MOSAIC label specifies a 4,500 mAh battery. The owner reports that the lithium battery is soldered into the board assembly. The exact cell chemistry, nominal voltage, cell arrangement, pack dimensions, protection board, temperature sensor and wiring layout have not yet been confirmed.

Board attachment: Soldering is owner-reported, but the precise interface is not yet documented: we do not know whether pack leads are soldered to PCB pads, whether cell tabs are welded to leads, or how the protection and charging circuitry is arranged.

A future replacement must be treated as battery-pack and board-level service—not as permission to solder directly to a bare lithium-ion cell. The replacement must match the original electrical specifications and retain appropriate protection and charging controls.

Safety: Do not heat, puncture, short, or solder directly to a bare lithium-ion cell. Do not open the device or buy a replacement pack until its exact specifications and protection circuitry have been identified. Battery work is reserved for a qualified technician.

Photo preservation note: The earlier board photo is not currently available as a reusable image file in this repository. The chip identification is documented from the earlier visual review, but a fresh copy of the original photo is needed before embedding it here. We will not substitute a generic chip photograph and imply it is the MOSAIC board.
